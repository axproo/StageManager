# StageManager

Application web de gestion des stages.

## Description

StageManager est une application permettant de gérer les stages :
- gestion des étudiants
- gestion des demandes de stage
- suivi des informations liées aux stages

## Technologies utilisées

- Vue 3
- TypeScript
- Vite
- Pinia
- Vue Router
- Tailwind CSS
