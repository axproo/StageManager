# Workflow Git

Tous les développements suivent le workflow suivant.

```
Issue

↓

Créer une branche

↓

Développer

↓

Commit

↓

Push

↓

Pull Request

↓

Code Review

↓

Corrections

↓

Merge dans develop
```

## Convention de nommage

```
feature/authentication

feature/users

feature/dashboard

feature/tasks

bugfix/login

hotfix/api
```

## Convention de commit

```
feat:

fix:

docs:

style:

refactor:

test:

build:

chore:
```

## Règle

Un commit doit représenter une seule modification logique.

Les commits "test", "update" ou "modification" sont interdits.
