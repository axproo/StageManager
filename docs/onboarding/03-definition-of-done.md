# Definition of Done

Une Issue est considérée comme terminée uniquement si toutes les conditions suivantes sont remplies.

## Développement

* Fonctionnalité terminée.
* Code factorisé.
* Code documenté.

---

## Tests

* Fonctionnalité testée.
* Aucun bug connu.

---

## Git

* Branche à jour.
* Historique propre.

---

## Pull Request

* Créée.
* Relue.
* Validée.

---

## Documentation

Documentation mise à jour.

---

## Validation

L'encadrant valide la Pull Request.
