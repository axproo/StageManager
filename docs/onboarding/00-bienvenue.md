# Bienvenue chez Axproo

## Bienvenue

Vous rejoignez l'équipe de développement de **StageManager**.

Durant votre stage, vous travaillerez sur une application réelle en respectant les méthodes de travail de l'entreprise.

Vous ne réaliserez pas des exercices scolaires.

Vous participerez au développement d'un produit.

Chaque fonctionnalité sera développée comme dans une équipe professionnelle.

---

# Votre mission

Développer une plateforme de gestion des stagiaires.

L'application permettra de gérer :

* les utilisateurs ;
* les stagiaires ;
* les départements ;
* les présences ;
* les tâches ;
* les rapports ;
* les statistiques.

---

# Organisation

Vous travaillerez en équipe.

Chaque fonctionnalité sera attribuée sous la forme d'une **Issue**.

Une Issue correspond à une fonctionnalité.

Une fonctionnalité correspond à une Pull Request.

---

# Votre rôle

Chaque développeur est responsable de son code.

Vous devrez :

* comprendre le besoin ;
* proposer une solution ;
* développer ;
* tester ;
* documenter ;
* corriger les remarques de revue de code.

---

# Ce qui est attendu

Vous devrez démontrer :

* votre autonomie ;
* votre capacité à rechercher une information ;
* votre capacité à travailler en équipe ;
* votre rigueur ;
* votre communication.

Bienvenue dans l'équipe.
