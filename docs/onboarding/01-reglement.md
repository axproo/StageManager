# Règlement de l'équipe

Les règles suivantes sont obligatoires.

## Git

* Interdiction de travailler sur `main`.
* Interdiction de pousser directement sur `develop`.
* Une branche par Issue.
* Une Pull Request par Issue.

---

## Code

Le code doit être :

* lisible ;
* documenté ;
* testé ;
* factorisé.

Le code dupliqué est interdit.

---

## Documentation

Toute nouvelle fonctionnalité doit être documentée.

---

## Communication

En cas de blocage supérieur à 30 minutes :

* rechercher une solution ;
* consulter la documentation officielle ;
* demander de l'aide à l'équipe.

---

## Pull Requests

Toute Pull Request devra être relue avant sa fusion.

Aucune exception.

---

## Respect des conventions

Tous les développeurs utilisent les mêmes conventions de nommage.

Aucune convention personnelle n'est autorisée.
